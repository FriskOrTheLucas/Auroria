# Auroria [.NT]
Hello! This is the Official Source Code for Auroria, A Roblox Launcher with clients!
Oh yeah, the launcher is open source too! Yipee!


# Why make the launcher open source?
Well, what if someone else wants to make a launcher. They have no idea where to start, or how to do certain things.
That's why it's nice to have Auroria be open source! So then people also making Launchers can look at the source
for reference!
